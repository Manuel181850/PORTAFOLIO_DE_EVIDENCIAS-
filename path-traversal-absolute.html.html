Burp Suite · Lab: File path traversal, traversal sequences blocked with absolute path bypass

Path Traversal: Absolute Path Bypass

Explotación de vulnerabilidad de salto de directorio donde las secuencias de escape (../) están bloqueadas, logrando un bypass mediante el uso de rutas absolutas (/etc/passwd)[cite: 6].

#PathTraversal #BurpSuite #AbsoluteBypass #WebSecurityAcademy #UPSLP

01 / Resumen técnico

¿En qué consistió la práctica?

Procedimiento técnico basado en la intercepción de peticiones y derivación de controles de seguridad.

⚑

Objetivo del Lab

Recuperar el contenido del archivo crítico del sistema /etc/passwd en una aplicación web que bloquea las secuencias de salto estándar (../)[cite: 6].

</>

Explotación (Payload)

Se interceptó la petición de imágenes GET /image?filename=68.jpg y se modificó directamente a una ruta absoluta: GET /image?filename=/etc/passwd[cite: 6].

🛡

Mitigación

Validar que los nombres de archivos no comiencen con caracteres de ruta absoluta, utilizar listas blancas estrictas y aislar el almacenamiento de archivos mediante chroot.

Nota académica: El procedimiento detallado, las capturas de pantalla de la intercepción en Burp Suite, el análisis del payload y la evidencia de resolución se encuentran integrados en el visor del reporte formal en PDF adjunto abajo[cite: 6].
