Análisis de Spyware Básico en Python

Evaluación técnica de un script en Python con funcionalidad de keylogger, realizada en un entorno controlado con fines exclusivamente académicos dentro de CNO IV – Seguridad Informática.

#Python #Spyware #Ciberseguridad #UPSLP

01 / Resumen ejecutivo

¿Qué se analizó?

Contexto general del script evaluado y de la amenaza que representa este tipo de programa.

◉

¿Qué hace?

Se trata de un keylogger: un script que se ejecuta en segundo plano y registra continuamente la actividad de teclado del equipo, guardando cada evento en un archivo de registro local.

</>

Bibliotecas utilizadas

El script se apoya en librerías estándar y de terceros de Python para el manejo de fecha/hora y para la escucha de eventos de teclado a nivel de sistema operativo.

⚠

Implicaciones

No requiere privilegios elevados para operar y puede capturar contraseñas, mensajes y cualquier información sensible que se escriba mientras el proceso está activo, comprometiendo la confidencialidad del usuario.

Nota académica: por política de uso responsable, esta página no reproduce ni explica el código del script línea por línea. El desglose técnico completo (bibliotecas específicas, funciones y flujo del programa) se documenta en el reporte formal, en la sección "Análisis Técnico del Código".
