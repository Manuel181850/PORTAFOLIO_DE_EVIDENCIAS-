Explicación de la Vulnerabilidad

Ocurre cuando una aplicación web procesa entradas del usuario (como parámetros de archivos) sin realizar una validación o saneamiento adecuado, permitiendo utilizar secuencias de escape de directorios (../) para navegar fuera del directorio web raíz.

🛡

Mitigación Recomendada

Evitar pasar rutas de archivos directamente desde los parámetros del cliente. Implementar listas blancas estrictas (whitelists) o utilizar funciones seguras del lenguaje que resuelvan la ruta absoluta dentro del directorio permitido (por ejemplo, basename()).
