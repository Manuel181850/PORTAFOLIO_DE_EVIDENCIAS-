Burp Suite · Actividad 12: File path traversal, validation of file extension with null byte bypass

Path Traversal: Null Byte Bypass

Explotación de vulnerabilidad de salto de directorio evadiendo la validación obligatoria de extensión mediante el uso de un byte nulo.

#PathTraversal #BurpSuite #NullByte #WebSecurityAcademy #UPSLP

01 / Resumen técnico

¿En qué consistió la práctica?

Análisis de un sistema que exige una extensión de archivo estricta, burlado mediante la técnica de truncamiento por byte nulo.

⚑

Objetivo del Lab

Superar la validación que exige que el parámetro finalice con una extensión específica para leer el archivo /etc/passwd.

</>

Explotación (Payload)

Se aplicó el payload ../../../etc/passwd%00.png desde el Repeater de Burp Suite, satisfaciendo la validación de la extensión mientras el servidor trunca la cadena.

🛡

Mitigación

Actualizar componentes de software a versiones modernas donde el manejo de cadenas nativo no sea susceptible a bytes nulos, y utilizar listas blancas estrictas de nombres de archivos permitidos.

Nota académica: Las capturas de pantalla de la intercepción en el Repeater y la evidencia del laboratorio resuelto se encuentran integradas en el reporte formal correspondiente.
