Burp Suite · Actividad 10: File path traversal, traversal sequences stripped with superfluous URL-decode

Path Traversal: Superfluous URL-Decode

Explotación de vulnerabilidad de salto de directorio mediante evasión de filtros con codificación URL superflua (múltiple) para la lectura del archivo /etc/passwd.

#PathTraversal #BurpSuite #SuperfluousDecode #WebSecurityAcademy #UPSLP

01 / Resumen técnico

¿En qué consistió la práctica?

Análisis de un mecanismo de saneamiento defectuoso que descarta secuencias prohibidas antes de aplicar una decodificación adicional.

⚑

Objetivo del Lab

Bypassear el bloqueo de secuencias de escape en el parámetro filename para extraer de forma no autorizada el archivo del sistema /etc/passwd.

</>

Explotación (Payload)

Se empleó el payload con codificación doble ..%252f..%252f..%252fetc%252fpasswd interceptado y enviado desde el Repeater de Burp Suite.

🛡

Mitigación

Asegurar que la decodificación de la URL ocurra una sola vez y de forma centralizada antes de cualquier validación de expresiones regulares, o bien utilizar funciones seguras de mapeo de archivos.

Nota académica: Las capturas de pantalla con la traza de la petición HTTP, el análisis en el Repeater y la evidencia del estado "LAB Solved" se encuentran integradas en el reporte correspondiente.
